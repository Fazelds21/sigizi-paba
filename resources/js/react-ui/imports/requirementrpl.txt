
Design a complete responsive web application called **SiGizi PABA (Sistem Informasi Gizi Pambalang Batu)**.



The web is a healthcare and nutrition management platform that connects parents/patients, nutritionists, and administrators.



Create a modern, professional, clean healthcare UI with a desktop-first approach.



---



## DESIGN STYLE



* Modern Healthcare Dashboard

* Clean and minimalist

* Professional medical appearance

* Rounded corners (12–16px)

* Soft shadows

* Spacious layout

* Responsive design

* Accessible UI

* Consistent design system



### Color Palette



Primary:



* Green (#2E7D32)



Secondary:



* Light Green (#81C784)



Accent:



* Blue (#42A5F5)



Background:



* White (#FFFFFF)

* Light Gray (#F5F7FA)
